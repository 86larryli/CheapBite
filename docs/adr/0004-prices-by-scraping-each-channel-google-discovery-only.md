# Prices come from scraping each Channel; Google Maps is discovery-only

"Order with Google" was discontinued: since **July 1, 2024** the "Order online" panel on Google Search/Maps no longer displays menus or prices — it only redirects the user to choose a provider's (or the restaurant's own) site. So Google Maps is useful to CheapBite **only for discovering the Channel set** — which Providers exist for a restaurant and their links — not for reading prices.

Therefore each Channel's item prices must be obtained by **scraping that Channel's own site** (Uber Eats, DoorDash, Grubhub, or the Direct site's Ordering Backend). There is no shortcut where we read comparable prices out of Google.

This is an external constraint, not a preference — recorded so the "just read the prices from Google" shortcut isn't proposed again. Source: Google's June-2024 announcement and the subsequent redirect-only behavior.
